## Struktur persistence dan provenance

Tetap menggunakan case/run/artifact/observation/custody. Mode run baru:

| Mode                 | Artefak immutable                                                                                                                                                                                                                                                            |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `forensic-import`    | `forensic-original` role `original-imported`, AES-256-GCM atas bytes persis unggahan; `forensic-import-metadata` terenkripsi berisi filename/options/importedAt/originalRef; `forensic-parse` terpilih; run-report + manifest. Hash baseline hanya dimulai pada waktu impor. |
| `forensic-parse`     | Parsing ulang / adapter capture: artefak `forensic-parse` baru, parent source run, cross-run originalRef, config parser version/source ID tanpa rahasia; report + manifest.                                                                                                  |
| `forensic-operation` | Record bookmark/note/hypothesis/clock-skew/merge/revert, analis, alasan, waktu host, referensi sumber dan extraction version, report + manifest.                                                                                                                             |
| `forensic-share`     | Artefak role `redacted`, sharePolicy `strict-structural-v1`, report + manifest; tidak menyertakan original bytes.                                                                                                                                                            |

`derivedFrom` tetap hanya ID pada run yang sama. Hubungan lintas run disimpan eksplisit di JSON sebagai `{caseId,runId,artifactId,sha256}`. Event/field menambah `{parser:{id,version}, location, method, extractionRef}`. ID event adalah `<parseArtifactId>:eN`, ID entity occurrence menambah `:entity:N`; tidak memakai indeks/selector lepas lintas capture. Hasil parsing mempunyai options, sourceCollectionTime, coverage/status/gapCount/gaps, redactions, limits dan limitations. Rekonstruksi UI membaca record terverifikasi; bytes rusak tidak digunakan sebagai event terpercaya.

Semua run analisis mempunyai collectorActions offline dan privacy policy yang sesuai. File asli memang dapat mengandung cookie/password/payload dari unggahan; ini tidak boleh disamakan dengan kebijakan collector browser yang sejak awal menghilangkan nilai tersebut. Metadata private disimpan sebagai artefak terenkripsi, bukan raw filename/body di run configuration/custody. Preview menambahkan event penanganan, parsing sukses/gagal dicatat, reject ukuran/path/options dicatat ketika belum ada original. Run yang terputus dipulihkan partial pada restart; sumber tanpa parsing bisa diparse ulang.

## Skema waktu

- `event.time`: `{raw,zone,normalized,status,basis,assumedZone?,reason?,precision?}`. Raw menyimpan pernyataan sumber yang dibatasi, lokasi asli tetap tersedia. Normalized adalah UTC ISO millisecond; fractional precision lebih tinggi tetap ada di raw. `known-offset` bukan verifikasi jam.
- Tanpa offset: `ambiguous` dan normalized null. Analis dapat memilih fixed offset sehingga menjadi `assumed-zone`; tidak menggunakan timezone host sebagai tebakan. Ambiguous calendar syntax/date-only/unsupported named zone tidak ditebak; invalid calendar/leap second ditandai invalid.
- RFC negative zero (`-0000` / `-00:00`) menggunakan UTC instant yang dinyatakan, dengan status `unknown-local-offset`: informasi zona lokal masih tidak diketahui. Bukan sama dengan timestamp tanpa offset.
- Unix seconds/milliseconds hanya bila dipilih eksplisit; HAR tetap ISO dan email memakai profil Date tersendiri.
- `collectedTime`: klaim pengumpulan file dari operator bila diisi, selain itu unknown. Untuk capture baru, memakai waktu artefak host. Collection time legacy tetap unknown; waktu baseline legacy ditempatkan sebagai importedTime. `importedTime`: waktu host saat file masuk (tidak berubah ketika reparse), null untuk adapter capture. `parsedTime`: waktu analisis baru. Semua timestamp host menyimpan IANA zone/offset dan catatan bahwa jam tidak diattest.
- `displayTime` dapat memakai satu clock-skew aktif per sumber, detik bulat ±86400, dengan operation ID/reason/operator. Nilai `time` dan artefak tidak diubah; undo mengembalikan tampilan. Unknown time tidak menjadi known karena skew.
- Tampilan 5.000 event terpilih, UTC yang dikenal diurutkan, unknown di akhir. Ini batas tampilan, bukan jaminan semua kejadian kasus terwakili. Pilih sumber untuk event yang tidak muncul di proyeksi kasus besar.

## Graph dan batas kesimpulan

File, hash, event/request, URL, domain, IP, account, email ID, session claim dan collector session adalah occurrence terpisah. Source→event menggunakan declared untuk impor dan observed untuk request collector. Nilai sama dikelompokkan melalui hub **correlated**; tidak ada edge kausal berdasarkan kedekatan waktu. Domain/IP menunjukkan klaim sumber, bukan pemilik infrastruktur. Akun/email sender bukan identitas terautentikasi.

URL matching memakai URL penuh sebelum display redaction dengan HMAC khusus kasus; URL berisi query berbeda yang tampil sama tidak otomatis dihubungkan. Account menggunakan string persis; IP dinormalisasi tanpa DNS lookup. Request ID/session claim hanya lintas file jika namespace yang sama dinyatakan operator; default dibatasi source ID. Session claim value hanya menjadi referensi HMAC opak, bukan cookie/token plaintext. Sesi observed hanya kontinuitas BrowserContext yang disimpan collector, bukan autentikasi pengguna, dan tidak disambungkan lintas run.

Hash terhitung atas file/decoded MIME dibedakan dari hash yang hanya dinyatakan log. SHA sama dapat menghubungkan bytes ekuivalen; tidak membuktikan asal, pengirim atau waktu yang sama. Merge manual adalah group inferred dengan catatan, mempertahankan node sumber. Hypothesis status tidak memiliki transisi otomatis ke validated/security finding. Referensi versi lama tetap sah; pembacaan latest tidak memindahkan kesimpulan lama diam-diam.

Capture sekarang memperlihatkan keadaan saat diamati. App tidak menyatakannya sebagai rekonstruksi peristiwa 2025 hanya karena domain/URL cocok dengan log 2025. Timestamp/akun yang ditulis file juga dapat dipalsukan. Hash/GCM/custody lokal membuktikan konsistensi dengan baseline lokal, bukan keaslian sumber, waktu historis, kelengkapan koleksi atau kekebalan administrator host yang menguasai database dan kunci.

## Batas input, preview dan berbagi

- Upload binary `application/octet-stream`: 8 MiB, tanpa decompression, timeout body 10 detik. Filename harus basename (tanpa slash/backslash/colon/control); tidak menjadi filesystem path. UUID/reference harus anggota kasus yang sama. Origin/Host/Sec-Fetch guard dan bind loopback tetap berlaku.
- Worker: wall timeout 3 detik, old heap 96 MiB, young 16 MiB, stack 4 MiB, output JSON 12 MiB; maksimal 2 parse bersamaan dan 1 per kasus. Ini batas sumber daya lokal, bukan sandbox OS untuk eksekusi malware; tidak ada eksekusi konten.
- JSON maksimal 50.000 node/24 depth; 1.000 event/parse; 5.000 baris dan 100 kolom CSV, cell 100.000 karakter. Nilai skalar >8192 dilewati; display field >500 dipotong dengan gap. MIME header 64 KiB, 40 parts, depth 8. URL body dibatasi. Original tetap utuh, sehingga truncation ekstraksi bisa ditinjau.
- Kasus: 100 import originals, 20 reparses per source, 300 operations, budget artifact impor/parsing 128 MiB termasuk reserve 21 MiB untuk input/output/metadata berikutnya. Ini bukan batas disk global lintas kasus, capture lama, analyst operations atau share history. Batas artefak 20 MiB/run 128 MiB tahap 1 tetap berlaku. Ekspor kasus sangat besar dapat ditolak pada batas artefak.
- Preview React text/JSON saja. HTML email, formulas, scripts, SVG, attachments dan archives tidak dieksekusi, dirender atau diekstrak. Tidak ada remote-image fetch. Original diberikan sebagai octet-stream attachment UUID, `nosniff`, CSP `default-src 'none'; sandbox`.
- HAR cookie/auth/body tidak ikut parsing; nilai session dipseudonimkan, URL query/credentials/fragment disamarkan. Parser log hanya field yang dipetakan, bukan seluruh payload. Private parsing masih dapat memuat PII di akun, subject, URL path dan field analis; tidak diklaim sebagai PII sanitizer universal.
- Ekspor berbagi menghilangkan semua label/nama file/field values/raw times/mapping namespaces/matching keys/teks analis/originals. Normalized times, hash terhitung (hash deklaratif disamarkan), evidence IDs dan struktur graph dipertahankan dan masih bisa linkable. Coverage status/jumlah gap tetap tersedia; detail alasan berada di artefak parsing privat. Manifest/custody biasa tetap privat. Hash diperiksa ulang sebelum preview/share/download; kerusakan membatalkan ekspor.
- Tidak ada network request dari pipeline forensik, query URL, DNS/entity enrichment, atau replay. Isolasi jaringan collector yang lama tidak diperluas: DNS check dan actual socket dapat berbeda, sehingga tidak ada klaim SSRF/egress isolation lengkap. Developer app lokal belum layanan multiuser/hostile-tenant.

## Rujukan semantik

Diperiksa saat implementasi, digunakan untuk batas profil, bukan klaim seluruh standar didukung:

- [RFC 4180](https://www.rfc-editor.org/rfc/rfc4180.html): quoted CSV fields, doubled quotes, multiline. Dukungan delimiter tambahan adalah opsi parser app.
- [RFC 5322 §3.3](https://www.rfc-editor.org/rfc/rfc5322.html#section-3.3): email date/time dan arti -0000; parser app hanya profil grammar terbatas.
- [RFC 3339 §4.3](https://www.rfc-editor.org/rfc/rfc3339.html#section-4.3): UTC instant vs unknown local offset -00:00; log tanpa offset diperlakukan berbeda.
- [RFC 2045](https://www.rfc-editor.org/rfc/rfc2045.html): MIME transfer encodings. Tidak ada klaim validasi MIME/signature lengkap.
- [Chrome DevTools: HAR export](https://developer.chrome.com/docs/devtools/network/reference#save-as-har): HAR dapat berisi data sensitif; profil importer mengambil field terbatas dan mempertahankan sumber asli privat. Draft HAR W3C yang ditinggalkan tidak diperlakukan sebagai standar aktif.
